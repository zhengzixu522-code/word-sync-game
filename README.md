# 同频词语 - 双人联想小游戏

一个可以让两台设备通过浏览器联机玩的双人词语联想游戏。这个版本只需要 Node.js，**不需要安装任何第三方依赖**。

## 玩法
1. 玩家 A 创建房间，把 5 位房间号发给玩家 B。
2. 玩家 B 输入房间号加入。
3. 两人各自写下一个词。提交后，对方在自己提交之前看不到你的答案。
4. 两人都提交后，同时揭晓：
   - 词语相同：同频成功，游戏结束。
   - 词语不同：立刻进入下一轮，并显示 20 秒联想倒计时。
5. 双方根据刚才的两个词继续联想并填写下一个词，重复直到相同。

> 为避免其中一人没来得及填写导致整局永久卡死，倒计时到 0 后仍允许提交；界面会提示“时间到”。如果你希望严格执行 20 秒超时惩罚，也可以继续改。

## 运行
需要 Node.js 18 或更高版本。

在项目文件夹打开终端：

```bash
npm start
```

然后打开：

```text
http://localhost:3000
```

## 两台设备在同一个 Wi-Fi 下玩
假设运行服务器的电脑局域网 IP 是 `192.168.1.10`，另一台手机/电脑打开：

```text
http://192.168.1.10:3000
```

如果 Windows 防火墙弹窗，请允许 Node.js 在“专用网络”中通信。

## 异地联机
如果两个人不在同一个 Wi-Fi，需要把项目放到公网服务器。任何支持长期运行 Node.js HTTP 服务的平台都可以使用。

启动命令：

```text
npm start
```

程序会自动读取服务器提供的 `PORT` 环境变量。

## 已实现
- 5 位房间号创建/加入
- 两名玩家联机
- 双方答案隐藏提交
- 两人都提交后同时揭晓
- 不同词后自动进入下一轮
- 20 秒联想倒计时
- 相同词自动判定成功
- 每轮词语历史轨迹
- 重新开始
- 手机/电脑自适应界面
- 无第三方 npm 依赖
